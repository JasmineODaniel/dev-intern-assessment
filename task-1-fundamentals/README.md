# Task 1: Fundamentals (about 60–75 minutes)

`exercises.js` contains 8 empty functions. Your job is to make each one work.

## How to run the tests

- **Browser:** open `tests.html`. Refresh the page each time you save `exercises.js`.
- **Node (optional):** from this folder, run `node exercises.test.js`.

At first every test fails. That is expected.

## What to do

1. Work through the functions in order. They get harder as you go.
2. Number 8 is a **stretch** exercise. Try it only if you have time. Tests marked `[stretch]` are optional.
3. You are welcome to add your own tests at the bottom of `exercises.test.js`. Please don't change the tests that are already there.

## Write in NOTES.md

- Pick **one** function you found tricky. In plain English, explain how your solution works, as if you were telling a classmate who can't see the code.
- If a test failed for a while, what was wrong and how did you work it out?

## Tips

- Read the comment above each function and look at its tests. Together they are the full specification.
- Get one test passing, then move on to the next. Don't try to solve everything at once.
- A readable answer is better than a clever one.
